### [Kagi](https://kagi.com)

#### Install using Git

If you are a git user, you can install the theme and keep up to date by cloning the repo:

```bash
git clone https://github.com/dracula/kagi.git
```

#### Install manually

Download using the [GitHub `.zip` download](https://github.com/dracula/kagi/archive/main.zip) option and unzip them.

#### Activating theme

1. Open [Kagi Settings → Appearance → Custom CSS](https://kagi.com/settings?p=custom_css).
2. Turn on **Enable Custom CSS**.
3. Copy the entire contents of [`custom.css`](./custom.css) and paste them into the text area.
4. Click **Apply Custom CSS**.

The theme follows your system's color scheme — Dracula for dark mode and Alucard for light mode.

> **Tip:** If something breaks, add `?no_css` to any Kagi URL (for example, `kagi.com/search?q=test&no_css`) to temporarily disable custom CSS.
